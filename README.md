# Discrete Mathematics Worksheets & Exercises

This repository contains the interactive problem-solving notebooks and code exercises for Year 2 Discrete Mathematics / Algorithms & Complexity.

## Contents

- `week_01_fibonacci.ipynb` — Fibonacci numbers, recursion, iterative and dynamic methods
- `week_02_complexity_notation.ipynb` — Big-O, Omega, Theta asymptotic analysis
- `week_03_divide_and_conquer.ipynb` & `mergesort.py` — Divide and conquer foundations, Merge Sort
- `week_04_divide_and_conquer_2.ipynb` — Master Theorem and advanced divide-and-conquer
- `week_05_dynamic_programming.ipynb` & `rod_cut_bottom_up_cost_to_cut.py` — Dynamic programming, rod cutting, memoization
- `week_06_greedy_algorithms.ipynb` — Greedy choice property and optimal substructure
- `week_07_graphs.ipynb` & `week_07_dijkstra.ipynb` — Graph representations, shortest path (Dijkstra)
- `week_08_various_topics.ipynb` — Advanced & supplementary algorithmic topics

## Setup & Running Locally

1. Create and activate a Python virtual environment:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Launch JupyterLab or Notebook:
   ```bash
   jupyter lab
   # or
   jupyter notebook
   ```
   Alternatively, you can open and execute any `.ipynb` file in VS Code or upload it to Google Colab.
